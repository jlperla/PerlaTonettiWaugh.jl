
### Deprecated

This repository contains the orginal complete code used to calibrate the model and to compute equilibrium steady-state and transition dynamics of the model in [Equilibrium Technology Diffusion, Trade, and Growth](https://christophertonetti.com/files/papers/PerlaTonettiWaugh_DiffusionTradeAndGrowth.pdf) by Perla, Tonetti, and Waugh (AER 2021).

See [Corrigendum: Equilibrium Technology Diffusion, Trade, and Growth](https://christophertonetti.com/files/papers/PerlaTonettiWaugh_Corrigendum.pdf) for a corrected solution of the model with geometric Brownian motion (GBM) productivity shocks.  An full replication and calibration of the corrected results is in [https://github.com/HighDimensionalEconLab/perla_tonetti_waugh/)](https://github.com/HighDimensionalEconLab/perla_tonetti_waugh/).
